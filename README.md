# AI Resume Screening System 🚀

An AI-powered Resume Screening System built using **Django**, **Python**, and **Machine Learning (TF-IDF)** to evaluate how well a resume matches a job role.

---

## 🔍 Features

- Upload resume as **PDF** or paste resume text
- Select job role dynamically
- AI-based resume–job matching
- Match score with animated progress bar
- Confidence level (Strong / Moderate / Low Match)
- Matched & Missing skill analysis
- Improvement tips for better score
- Admin panel to manage job roles and results


## ⚙️ Tech Stack

- **Backend:** Django (Python)
- **Frontend:** HTML, CSS
- **Machine Learning:** TF-IDF (Scikit-learn)
- **Database:** SQLite
- **Version Control:** Git & GitHub
